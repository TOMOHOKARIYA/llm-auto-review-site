llm-auto-review

Google ドキュメントへのレビュー指摘を、コメントと提案として書き込む個人用ツール

概要

llm-auto-review は、開発者本人が自分の Google ドキュメント（教材原稿など）を校閲するために使う、個人用のローカルツールです。AI アシスタントが作成したレビュー指摘を、Google Docs API を使って文書の該当箇所へコメントまたは提案として追加します。

一般公開されたサービスではありません。利用者は開発者本人に限られます。

Google アカウントで許可を求める範囲

  • Google ドキュメントの表示・編集：指定した文書の本文を読み取り、コメントと提案を追加するため
  • メールアドレスの表示：想定したアカウントでログインしているかを確認するため

プライバシーポリシー

About (English)

llm-auto-review is a personal, locally run tool used only by its developer. It reads the developer's own Google Docs and adds review comments and suggestions through the Google Docs API. It is not offered as a service to other users.
