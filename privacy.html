プライバシーポリシー

llm-auto-review ／ 最終更新日：2026年10月2日

1. 対象

本ポリシーは、個人用ローカルツール「llm-auto-review」（以下「本ツール」）が Google ユーザーデータをどのように扱うかを定めます。本ツールの利用者は開発者本人に限られます。

2. 取得するデータ

  • 利用者が指定した Google ドキュメントの本文、書式、既存のコメントと提案
  • 利用者が指定した Google ドライブ上のファイルの版履歴（各版の本文）と、解決済みを含むコメント（読み取りのみ）
  • ログイン中の Google アカウントのメールアドレス

3. 利用目的

  • 文書の本文を読み取り、利用者自身の指示によるレビュー指摘を、コメントまたは提案として同じ文書に追加するため
  • 過去の版と人手のレビューコメントを照らし合わせ、本ツールのレビュー精度を利用者自身が評価するため
  • 想定したアカウントで認証されているかを確認するため

上記以外の目的には使用しません。広告、プロファイリング、販売には一切使用しません。

4. 保存

認証トークンと、作業中に書き出した文書テキスト・レビュー結果は、利用者のコンピュータ内にのみ保存します。本ツールが外部のサーバーにデータを保存することはありません。

5. 第三者への提供

本ツールは Google ユーザーデータを第三者に販売・提供しません。ただし、利用者本人がレビューのために使用する AI アシスタント（Anthropic 社の Claude）に、利用者自身の操作で文書のテキストを渡すことがあります。この場合のデータの扱いは、利用者と当該サービスとの契約に従います。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールが Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

7. データの削除・アクセスの取り消し

利用者は Google アカウントのサードパーティ アクセス設定 から、いつでも本ツールへのアクセス権を取り消せます。ローカルに保存したデータは、該当ファイルを削除すれば消去されます。
